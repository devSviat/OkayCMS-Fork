# Оновлення: мінімум товарів для індексації фільтра за брендом у категорії

Дій не потрібно. Поки поле порожнє, `/catalog/x/brand-y` віддає ті самі robots і карту сайту,
що й раніше, без додаткових запитів.

## Навіщо

Бренд-фільтр категорії з одним-двома товарами — тонка сторінка, яка майже дублює картку товару.
Закрити такі сторінки налаштуванням `robots_category_brand` можна було лише разом з усіма
бренд-фільтрами.

## Що додано

«Налаштування індексації» → колонка robots → «Мінімум товарів для індексації фільтра за брендом
у категорії»:

| Налаштування | Типово | Що означає |
| --- | --- | --- |
| `robots_category_brand_min_products` | порожньо (0) | мінімум товарів у лістингу бренд-фільтра категорії |

Порожнє поле, 0 чи значення поза межами 1–100000 зберігається як 0 і вимикає перевірку.
Рядка в `settings` для цього не треба.

## Яка сторінка підпадає

`/catalog/x/brand-y` з рівно одним брендом, без властивостей і `filter-*`, без пошуку. Товарів
рахується стільки ж, скільки показує лістинг (`paginate()`): видимі товари видимого бренду в
категорії з підкатегоріями, при `missing_products = hide` — лише в наявності.

| Товарів | robots | карта сайту |
| --- | --- | --- |
| менше за мінімум | щонайменше `noindex,follow` | немає |
| не менше | як за `robots_category_brand` | як раніше |

Суворіше значення `robots_category_brand` (`noindex,nofollow`) лишається. Пагінація й
`page-all` такої сторінки теж отримують щонайменше `noindex,follow`. Canonical не змінюється.
Метадані (SEO-шаблони фільтра) рахують robots без кількості товарів і лишаються як були.

## Для розробника

- `MetaRobotsHelper::getCatalogRobots()` приймає п'ятим аргументом кількість товарів сторінки;
  без нього (`null`) перевірки немає. `CategoryController` передає `total_products_num`, який уже
  порахував `CatalogHelper::paginate()`.
- `MetaRobotsHelper::getCategoryBrandMinProducts()` і `isBelowCategoryBrandMinProducts()` —
  через `ExtenderFacade`.
- `SiteMapHelper::filterCategoryBrandsByMinProducts()` рахує товари всіх брендів категорії одним
  запитом (`ProductsEntity::countGroupedByBrand()` з `BrandFeatureLandingsHelper::getCountFilter()`).
